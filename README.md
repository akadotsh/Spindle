# Spindle

<p align="center">
  <img src="assets/spindle.png" alt="Spindle logo" width="420">
</p>

Spindle is a Go SDK and terminal app for working with object storage across providers.

**Providers:** Cloudflare R2, Cloudinary, Google Cloud Storage, Neon Object Storage, Supabase, Upstash Blob, UploadThing, Vercel Blob, and local filesystem.
